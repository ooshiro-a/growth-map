# grops（旧名：成長の地図）要件定義（v2.10・2026年10月4日）
## 1. 目的
- 辛い時と年末年始に、自分の成長と進む方向を数分で確かめて書き足せるようにする
- 一番の目的は、成長の可視化と指針（進む方向）の明確化
- 使う場面は「辛い時（目標と指標を見て立ち上がる）」と「年末年始の振り返り・目標立て」。毎日は使わない
- 利用者は本人1人。PCとスマホの両方で使う（スマホでの見やすさを優先）
- 開いてから数秒で表示し、画面の切り替えで待たせない（読み込みは起動時に1回）
- 元になる考え方：書籍『成長マインドセット 心のブレーキの外し方』（吉田行宏）の「成長の地図」
  - アイスバーグ1つ、ブレーキ2つ（悩みブレーキ・大きな子どもブレーキ）、アクセル2つ（自分軸・理念アクセル、動機アクセル）
- 既存の「人生シート」（なりたい姿・なりたくない姿／逆算ロードマップ／アクションプラン）と人生マインドマップを、このアプリへ移行する
- 画面の見本：reference/mockup.html（文言・点数・日付はすべて例）
## 2. 原則
- 上書きしない：追加・修正・採点・状態変更・削除は、すべて日時つきの新しい記録として積み重ねる。過去の記録は書き換えない、消さない
- 削除した項目は消さずに灰色で表示し、点数には入れない（すべての画面で同じ）
- 間違えて足した項目は「…」→「完全に削除する」で画面から消せる（灰色の項目からも。すべての画面で同じ）
  - その項目の「追加」の記録を打ち消す行を足す。シートの行は消さない。画面にも履歴にも出なくなる
  - 木（人生マップ・アクションプラン）はこの先の枝もいっしょに消える。年ごとの種類は前の年の地図からも消える
  - 見るだけの年には出さない。人生マップの真ん中には出さない
- すべての項目に「…」ボタンを付け、PCとスマホの両方で「編集・追加・削除・履歴」を選べるようにする
- 過去の年は見るだけ（追加・編集の操作を出さない）
## 3. 構成
- 画面：React（Vite）。GitHub Pages（公開リポジトリ）で公開し、GitHub Actionsで自動組み立て・公開
- 保存：Google Apps Script（GAS）＋Googleスプレッドシート
  - GASは「行を足す」「全部読む」だけ。行の更新・削除はしない
  - PCとスマホで同時に書き込んでも壊れないようにする（例：LockService）
  - 今の姿と過去の姿は、画面側で行を読み込んで組み立てる
  - 参考：本人の既存アプリ「nippo」（GAS＋シート、PC・スマホ併用で動作中）の保存の仕組みとCORS対応
- 合言葉：すべての読み書きでGAS側が照合する
  - 合言葉はGASのスクリプトのプロパティに保存し、コードに書かない
  - 端末ごとに初回に1回入力。通ったらGASが「端末の鍵」（合言葉で署名した番号）を渡し、端末は鍵だけを記憶する。記憶が消えた時（iPhoneなど）は再入力
  - 10回続けて違えば30分止めるのは合言葉の照合だけ。鍵のある端末は、他の人がわざと止めても使える。合言葉を変えるとすべての鍵が使えなくなる
- 公開リポジトリのため、コードとリポジトリには合言葉・個人の記録・旧マインドマップの中身・本の図の写真を入れない
  - reference/ は .gitignore に入れる
  - 初期データは画面の取り込み機能から入れて、シートに保存する
- 書体：ゴシック体（例："Hiragino Kaku Gothic ProN","Hiragino Sans","Yu Gothic UI","Yu Gothic","Meiryo","Noto Sans JP",sans-serif）
- 配色：骨組みは 藍 #23628F・紙 #F5F2EA・金 #E2A63A の3色（アイコンと同じ）
  - 主ボタン・選択中・開いた「…」は藍。金は「いちばん新しい一歩」と太陽だけ（文字の色には使わない）
  - 朱 #C64A1E・松葉 #3E7D53・菖蒲 #6C55A3 は人生マップの枝と札（達成・向き合い中など）にだけ使う。墨 #2A2722 は文字
  - アイスバーグは紺 #1B2A6B と青の濃淡（#7BA7F2／#A6D0F7／#D5EEFB）。ダークでも図の中は同じ色（外枠と水面だけ明るくする）
- 画面の色：設定の「画面の色」で 端末に合わせる（既定）｜ライト｜ダーク。この端末だけの設定（端末の記憶 gm.theme。シートには書かない）
  - ダークは藍の夜の地（#0F2B3F）に紙色の文字。主ボタンは紙色の地に藍の文字
  - 本文の文字と地の差は 4.5:1 以上。人生マップの PDF はダークでも紙の色で作る
- 日時は日本時間で日時まで保存し、表示は「27年1月10日」のような年月日にする
## 4. 画面の並び
- スマホの下の切り替え：ホーム｜成長の地図｜振り返り｜人生マップ｜年表
- PCは左に同じ並びを出し、成長の地図と年表は中の画面も並べる
- 成長の地図の中：アイスバーグ｜ブレーキ｜アクセル
- 年表の中：アイスバーグ成長年表｜年ごとの記録
- 左上にアプリのアイコンと名前（PC は左の帯の上、スマホは上の帯の左。とても狭い画面はアイコンだけ）
- 右上の設定：画面の色、合言葉、初回の取り込み
## 5. 年ごとの成長の地図
- 成長の地図（アイスバーグ・ブレーキ・アクセル）は、年ごとに1つ持つ
- 1月1日以降に初めて開いた時に、自動で新しい年の地図を作り、前の年の最後の姿（項目・文言・状態・点数）を引き継ぐ
- 引き継がないもの：削除した項目（灰色）、外せたブレーキ。どちらも前の年の地図には残る
- 身についた言葉は「定着」のまま置いておく（終わらせる操作は「削除」だけ）
- 前の年は見るだけになる。ただし前の年の振り返り（答え合わせ・振り返り・来年の目標・抱負）は1月以降も書ける
- ホームの指標、人生マップ、振り返りの「長期」は年をまたいで続く
## 6. 画面
### ホーム（最初の画面）
- 上部に道のりの図：山の斜面に、書いた振り返り（四半期の②と年の②。1つの期は1点）の数だけ一歩ずつ点を打つ。古い順に下から並べ、いちばん新しい一歩は金。最大11点
  - 右上に「いちばん新しい一歩：26年3Qの振り返り」。まだない時は「最初の一歩は振り返りで書きます」
  - スマホは図を小さくし、文字は図の上に1行で出す
- 下に 指標｜今年の目標｜今の四半期の目標 の3列（スマホは1列で、この順に上から）
- スマホは下の切り替えに隠れず1画面に収める
  - 各項目は1行まで（はみ出す分は「…」。押すと全文と日付が出る）
  - 各欄に出すのは3件まで。超えた時は見出しに「ほか○件」を出し、押すと全部開く（もう一度押すと閉じる）
  - 指標の説明文は、指標がまだ無い時だけ出す
  - PC は件数も行数も絞らない
- 今年の目標：年末年始に「振り返り」で決めた、その年の目標を表示する
- 今の四半期の目標：振り返りの「四半期」で決めた、今の四半期（例：4Q（10〜12月））の目標を表示する。答え合わせは札だけ出す
- 指標：人生で指針にしている言葉・考え方
  - アイスバーグの「意識・想い・人生哲学」と同じ種類の言葉だが、全部を出すと見にくいので、見たい言葉だけを別に入れる
  - アイスバーグ、アクセルの自分軸・理念とはつながない（別に持つ）
  - 足す時は、手で打つか、その年のアイスバーグの「意識・想い・人生哲学」の言葉から選んで入れる（文言を写すだけ。後でアイスバーグ側を直しても指標は変わらない）
- どちらも「…」で編集・追加・削除・履歴ができる
### 成長の地図＞アイスバーグ
- 本の図と同じ三角形で描き、層の中に言葉を書き込む（本の記入例のように、短い言葉を中央寄せで並べる）
  - 図に出すのは「（」より前の部分で、10文字まで。それより長い時は10文字の後ろに「…」を付ける（全文は押した時に出す）
- 上から：成果（結果）＝水面の上・紺／能力・スキル／ふるまい・習慣・行動／意識・想い・人生哲学
- 水面の太い線は三角形の外まで伸ばす
- ふるまい・習慣・行動の層は、点線の下を«プラス»のふるまい（左）と«マイナス»のふるまい（右）に分け、真ん中に縦線を引く
- 採点するのは、能力・スキル、«プラス»のふるまい、意識・想い・人生哲学の言葉：目指す＝1点／実践中＝2点／定着＝3点
  - 言葉の前の小さな印で表す（目指す＝白丸、実践中＝半分塗り、定着＝黒丸）
  - 言葉を足す時・直す時にその場で選ぶ。選ぶ時に短い説明を小さく出す（目指す＝これから取り組む／実践中＝取り組んでいる／定着＝意識しなくてもできる）
- «マイナス»のふるまい（減らしたい行動）は点数に入れない。なくせたら削除（灰色）にする
- 層の点数＝その層の採点の合計。アイスバーグの大きさ＝3層の合計（削除した言葉は数えない）
- 層の見出しに点数を出す（例：能力・スキル 5点）。画面上部に大きさと、前年末からの増減を出す
- 成果（結果）：その年の目標のうち、振り返りの答え合わせで「達成」にしたものが自動で載る。点数はつけず件数を出す（PCは三角形の横に中身も出す）
- 言葉を押すと（PCはカーソルを合わせると）、小さく薄いグレーの日付と「…」が出る。もう一度押すと（PCは離れると）消える
  - アイスバーグの中だけは、図を読みやすくするため「…」を常には出さない
- 削除した言葉は灰色で残り、押すと（合わせると）追加日と削除日が出る
- 言葉の「…」：編集（文言・採点）／この層に追加／削除／履歴
- 画面右上の「＋追加」から、層を選んで言葉を足せる（空の層にも足せる）
- スマホ幅（約300px）でも層の中に言葉が収まるようにする。収まらない時の扱い（折り返し・拡大など）はフェーズ0で提案する
### 成長の地図＞ブレーキ
- 悩みブレーキ：悩みを追加し、次の2つを仕分ける
  - 分かれ道の悩み／決めた道の上の悩み
  - 自分で変えられる／変えられない
- 大きな子どもブレーキ：自分の中の「大きな子ども」が出た場面や傾向を追加
- どちらのブレーキにも「アクションプラン」（解くためにやること。複数行・空でもよい）を書ける。札の下に出し、ブレーキといっしょに翌年へ引き継ぐ。「…」の「アクションプランを書く／直す」からも開ける
- 状態：向き合い中／外せた。この年に外せた数を出す
- 外せたブレーキは翌年に引き継がず、その年の記録として残す
### 成長の地図＞アクセル
- 自分軸・理念：大切な言葉・価値観（ホームの指標とは別に持つ）。文言を直すと修正前の文言は履歴に残る
- 動機の四象限：自分×見える／他者×見える／自分×見えない／他者×見えない（区分は固定）
  - 各区分に0〜10点と、中身（何のために頑張るか）
  - 図：中心から各区分へ4本の矢印（長さ＝点数）。足し合わせた矢印は出さない
  - 前の年の4本を薄いグレーで重ねる
### 振り返り（前の「ノート」と1つにした）
- 書く時に「どの年の分か」を選ぶ（1月に前年分を書けるように）。書いた日時も残す
- 上から順に進める：①その年の目標の答え合わせ（達成／未達）②今年の振り返り ③来年の目標 ④来年の抱負
- 「達成」にした目標は、その年のアイスバーグの成果（水面の上）に載る
- ③の目標は、翌年のホームの「今年の目標」に出る
- 「年の振り返り」と「四半期」を切り替える。最初に出すのは、12月・1月は年の振り返り、ほかの月は四半期
- 長期（年をまたぐ）：逆算ロードマップ（仕事面／プライベート面）、アクションプラン（目標／手段：実行すること・頻度・打ち手）
#### 四半期の振り返り
- 1年を 1Q（1〜3月）・2Q（4〜6月）・3Q（7〜9月）・4Q（10〜12月）に区切る（日本時間）
- 年を選び、1Q〜4Q を選ぶ。最初に出すのは、四半期の最初の月（1・4・7・10月）は終わった前の四半期、ほかの月は今の四半期（1月は前の年の4Q）
- 上から順に進める：①その四半期の目標の答え合わせ（達成／未達）②その四半期の振り返り（文章）③次の四半期の目標
- 4Q の③は翌年の1Q の目標になる。③の目標は、その四半期になるとホームの「今の四半期の目標」に出る
- 未達にした目標は「…」から次の四半期へ写せる（まとめて写すこともできる。同じ文言がもう次の四半期にあれば写さない。履歴に「前の四半期から追加」と出る）
- 四半期の目標は年の目標とは別に持つ。達成してもアイスバーグの成果には載せない（成果は年の目標だけ）
- 書ける期間は年の振り返りと同じ（今年と前の年の分）。年ごとの記録でも見るだけで出す
### 人生マップ
- なりたい姿／なりたくない姿の木構造。年をまたいで続く
- 旧アプリ（reference/life-mindmap.jsx）の部品を流用：折りたたみ（たたんだ枝の数を表示）、拡大縮小、PDFで保存、文章として書き出す、元に戻す
- 項目を押すと選ばれて「…」が出る：文字を直す／枝を伸ばす／下に追加／削除／履歴
- 削除した項目は灰色で残し、追加日と削除日を出す
- 旧アプリの「元に戻す」は、打ち消しの記録を足す形にする
- 旧アプリの「最初の内容に戻す」は流用しない（履歴と番号が壊れるため）
### 年表＞アイスバーグ成長年表
- 直近5年のアイスバーグを横に並べ、成長していく様子を見せる（本の「アイスバーグの成長を描く」の図のように）
- 各年のアイスバーグは大きさ（点数）に比例させ、同じ縮尺で描く
- 各年の点数を点と線（橙）で結ぶ
- 下に表：年／大きさ／増減／成果
- 6年目からは古い年が外れる（年ごとの記録でいつでも見られる）
### 年表＞年ごとの記録
- 年を選ぶと、その年の成長の地図（アイスバーグ・ブレーキ・アクセル）と振り返りを見るだけで表示する
## 7. 日付の小さな表示（全項目で必須）
- 各項目の最後の変化を、小さく薄いグレーの文字で表示する（例：「27年1月10日に追加」「27年2月11日に修正」）
- 削除した項目は、追加日と削除日の両方を表示する
- PC：カーソルを合わせると表示し、離れると消える
- スマホ：押すと表示し、もう一度押すと消える
- 引き継いだ項目は、最初に足した日と、その年の変化の両方を表示する
- 全履歴（修正前の文言を含む）は「…」→「履歴」で見る
- アイスバーグの大きさと動機の矢印にも表示する（例：「27年12月20日に更新（21→23点）」）
## 8. 取り込み（初回）
- 設定の中に取り込み画面を置き、JSONまたは文章を貼って登録する（コードに初期データを書かない）
- 旧マインドマップ：旧アプリに追加する「番号つき書き出し」のJSON（id・text・children の木構造）を取り込む
  - 旧アプリの番号（id）は「n」＋時刻（36進数8桁）＋連番＋乱数の形
  - 「n」の後ろ8文字を36進数として読むと追加日時（ミリ秒）になるので、それを追加日にする
  - 読めない番号（root など）は取り込み日を追加日にする
  - 旧アプリの番号はそのまま引き継ぎ、以後の履歴をつなぐ
- 番号つき書き出しが使えない場合：旧アプリの「文章として書き出す」の形（行頭「- 」、字下げは2文字ずつ）を取り込み、追加日は取り込み日にする
- 成長の地図とホームの初期データ：下の形のJSONを取り込み、追加日は取り込み日にする
  - year：初期データの年（2026）
  - goals＝今年の目標、principles＝ホームの指標、axis＝アクセルの自分軸・理念
  - iceberg の layer：skill＝能力・スキル／plus＝«プラス»のふるまい／minus＝«マイナス»のふるまい／mind＝意識・想い・人生哲学
  - iceberg の stage：1＝目指す／2＝実践中／3＝定着（minus には付けない）
  - motives：selfVisible＝自分×見える／otherVisible＝他者×見える／selfInvisible＝自分×見えない／otherInvisible＝他者×見えない。score が null の区分は点数なしで取り込み、あとでアプリで入れる
  - brakes：kind は worry＝悩み／child＝大きな子ども。place は fork＝分かれ道／road＝決めた道の上。control は can＝変えられる／cannot＝変えられない。status は facing＝向き合い中／released＝外せた
```json
{
  "format": "growth-map-seed/1",
  "year": 2026,
  "goals": ["今年の目標"],
  "principles": ["指標"],
  "iceberg": [
    {"layer": "skill", "text": "技術力", "stage": 2},
    {"layer": "minus", "text": "マイナスの例"}
  ],
  "axis": ["自分軸・理念"],
  "motives": {
    "selfVisible": {"score": null, "items": ["お金を増やす"]},
    "otherVisible": {"score": null, "items": []},
    "selfInvisible": {"score": null, "items": []},
    "otherInvisible": {"score": null, "items": []}
  },
  "brakes": [
    {"kind": "worry", "text": "悩みの例", "place": "road", "control": "can", "status": "facing"},
    {"kind": "child", "text": "不機嫌を出す", "status": "facing"}
  ]
}
```
## 9. 運用
- シートの複製を毎月1回自動で作る（GASの時間指定。Google Driveの控えフォルダへ）
  - 毎月1日3時台。シートと同じフォルダの「（シートの名前）の控え」に、records だけを写した新しいスプレッドシートを置く。古い控えは消さない
  - 最後の控えの日と行数を設定に出す。40日以上前なら赤で知らせる
- 毎年12月25日頃に「振り返りの時期です」とメールで知らせる（GAS）
  - 12月25日9時台。宛先は自分（スクリプトのプロパティ NOTIFY_EMAIL で変えられる）。本文に記録の中身は入れない。同じ年は1回だけ
- 旧アプリ（claude.ai）の公開リンクは、取り込み完了後に本人が止める
